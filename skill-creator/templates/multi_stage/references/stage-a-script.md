# Stage 1: Script

## When to use

- The user just gave a one-line idea and has no script/outline yet
- The user wants to change a plot point, character, or dialogue in an existing script

## Steps

1. Confirm genre, length (suggest 3–6 scenes so later production does not explode), and tone (light / mystery / warm, etc.).
2. Output a structured Markdown script (not JSON), including:
   - One-sentence logline
   - Character list (name + one-line bio)
   - Scene list: scene description + key dialogue/narration
3. Ask the user to confirm the script. After confirmation, go to stage 2 (visuals and voice), or keep editing this stage if they ask.

## Notes

- Present the script as natural-language Markdown in the reply. No extra data structure is needed; later stages quote the script text from conversation history.
- For copyright, real-person likeness, and other sensitive setups, remind the user about compliance. Do not generate infringing content on your own.
